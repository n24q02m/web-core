## 2026-08-24 - Regex Alternation Performance Trap
**Learning:** Combining multiple regular expressions into a single alternation pattern (like `A|B|C`) can severely degrade performance if the individual patterns lack a common prefix. In such cases, the regex engine falls back to parallel search mode, evaluating every branch at every character position in the document. This disables fast-path optimizations (like Boyer-Moore) that the engine could use for literal string prefixes.
**Action:** Always prefer iterating sequentially over a list of compiled, independent regular expressions (especially if they start with different literal strings) over combining them into a single massive alternation. Couple this with fast-path substring checks (`in`) before executing the regex to significantly speed up processing large texts like HTML documents.
