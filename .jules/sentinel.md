## 2024-08-27 - [Missing SSRF Protection in Custom HTTP Client Fetching]
**Vulnerability:** Missing SSRF protection in `BasicHTTPStrategy` and `APIDirectStrategy` when fetching URLs. While `safe_httpx_client` includes automatic SSRF blocking via event hooks, these strategies bypass the event hooks when a custom `http_client` is injected. This allowed requests to private, loopback, or internal IP addresses if the user provided an unverified URL when a custom client was injected.
**Learning:** Security controls built into factory methods (like `safe_httpx_client`) only protect the default path. When providing dependency injection (like passing in a custom `http_client`), you must explicitly re-validate the input parameters at the strategy/action level before utilizing the injected dependency to ensure the security boundary is maintained.
**Prevention:** All web scraper strategies must explicitly validate all input and discovered URLs using `web_core.http.client.is_safe_url(url)` immediately upon entry to the `fetch` method, regardless of which HTTP client is being used to fulfill the request.
